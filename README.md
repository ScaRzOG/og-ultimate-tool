# OG Ultimate Tool

OG Sim Racing's app for Assetto Corsa: presets that make the game look real, live time and weather while you drive,
OG's own track skins and skies, servers and friends. BeamNG.drive and iRacing come later.

## Download

Get the latest installer from **[Releases](https://github.com/ScaRzOG/og-ultimate-tool/releases/latest)** and run it
once. From then on, OG updates itself when it opens.

It installs for your Windows user only, so it needs no admin rights. Remove it any time from Windows Settings → Apps.

OG isn't code-signed yet, so Windows SmartScreen may warn you the first time. Click **More info → Run anyway**. On a
PC with Smart App Control switched on, Windows may not run it at all until it is signed.

## What you need

- Assetto Corsa on Steam, with Custom Shaders Patch.
- Pure 3.59 or newer for OG's presets. OG tells you if yours is older.
- An OG account (email). It's the same account as on [ogsimracing.com](https://ogsimracing.com).

## What it changes

OG changes your game when you ask it to: a preset or a screen setup changes your graphics settings, Browse installs
OG's skins and presets, and Settings installs OG's in-game plugin. Every settings file it writes is backed up first.
Switch **OG manages my graphics** off and it leaves your graphics files alone. When it opens, OG keeps its own files
in your game up to date.

OG keeps a log of what it does and how your game is set up, and sends it to us while you're signed in, so we can fix
problems without asking you for screenshots. Turn it off any time in Your account. What's kept, and why:
[ogsimracing.com/privacy](https://ogsimracing.com/privacy).
