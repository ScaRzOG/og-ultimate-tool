# OG Ultimate Tool

Looks, recording and live modding for Assetto Corsa, built to sit next to Content Manager. BeamNG.drive and iRacing come later.

## Download

Get the latest installer from **[Releases](https://github.com/ScaRzOG/og-ultimate-tool/releases/latest)** and run it once. From then on, the app updates itself every time it starts.

It installs for your Windows user only, so it needs no admin rights. Remove it any time from Windows Settings → Apps.

The installer isn't code-signed yet, so Windows SmartScreen may warn you the first time. Click **More info → Run anyway**.

## Early days

This version only reads your Assetto Corsa setup. It doesn't change any game files yet.
